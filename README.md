## Featured project

**[Adaptive multimodal networks under missing modalities](https://github.com/MAJI-C/ada_mm_nn_missing_modalities)** (MSc thesis)

Distributed multi-node RGB-depth localisation of a moving object under a shared compute budget.

- Missing modalities compensated locally at each node; lost nodes handled by masked cross-station fusion
- A learned controller cut encoder compute by about **67%** at near-full accuracy
- Masking missing tokens outperformed synthetic CLS-token substitution
- Six model variants trained on the Snellius HPC cluster (Slurm)
